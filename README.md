# نظام إدارة درجات الطلاب

تطبيق سطح مكتب مصمم بلغة جافا وJavaFX لإدارة سجلات الطلاب وحساب إحصائيات فورية.

### 🚀 المميزات الأساسية
- **هيكل بيانات مخصص (`studentBag<T>`):** تطبيق حقيبة مخصصة تعتمد على المصفوفات بسعة تصل إلى 100 عنصر للتعامل مع أرقام الطلاب، أسمائهم، ودرجاتهم.
- **إدارة سجلات الطلاب:** إضافة، تحديث، حذف، والبحث عن سجلات الطلاب.
- **جدول تفاعلي (`TableView`):** مزامنة ديناميكية لواجهة المستخدم باستخدام `ObservableList` وربط تحديد الصفوف.
- **التحقق من صحة البيانات:** حماية مدمجة تمنع تكرار الأرقام الجامعية، الحقول الفارغة، والدرجات غير الصحيحة (خارج نطاق 0-100).
- **الإحصائيات والتحليلات:** حساب فوري لمتوسط الفصل (Class Average)، الدرجة القصوى، الدرجة الدنيا، وتكرار الدرجات.
- **توزيع البيانات مرئياً:** رسم بياني أعمدة (`BarChart`) ديناميكي يمثل نطاقات الدرجات (90-100، 80-89، 70-79، 60-69، وأقل من 60).

### 🛠️ التقنيات المستخدمة
- **لغة البرمجة:** Java (JDK 17+)
- **إطار عمل واجهة المستخدم:** JavaFX

### 📂 هيكلية المشروع

ملفsController.java: يدير منطق واجهة المستخدم لجافا إف إكس، معالجات الأحداث، حالات الأزرار، وربط البيانات.

ملفstudentBag.java: هيكل البيانات المخصص الذي يتعامل مع التخزين الأساسي للمصفوفة، البحث، والحسابات الإحصائية.

ملفStudentModel.java: كائن جافا بسيط (POJO) يعمل كحاوية لصفوف الجدول.
### ⚙️ طريقة التشغيل
1. افتح المشروع في بيئة تطوير الجافا NetBeans والتي تدعم JavaFX.
2. تأكد من ضبط مكتبة JavaFX SDK بشكل صحيح في مسار مكتبات أو وحدات المشروع.
3. قم بتشغيل نقطة الدخول الرئيسية للتطبيق.
